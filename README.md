# Girum Hospital Telemedicine Platform

A telemedicine web application built for Girum Hospital (Addis Ababa, Ethiopia), featuring appointment booking, video consultations, and an Amharic AI voice assistant for symptom triage. Built as a solo full-stack project.

## Status
In active development - Phase 0 (foundation setup)

## Tech Stack
Next.js, TypeScript, Supabase, Jitsi, Gemini API, Telebirr
