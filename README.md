# Girum Hospital Telemedicine Platform

![CI](https://github.com/issaadem/Girum-Telemedicine/actions/workflows/ci.yml/badge.svg)

A telemedicine web application built for Girum Hospital (Addis Ababa, Ethiopia), featuring appointment booking, video consultations, and an Amharic AI voice assistant for symptom triage. Built as a solo full-stack project.

## Status
Phase 1 (MVP Core) complete — patient signup/login, doctor browsing, appointment booking, and video consultations all working end-to-end.

## Tech Stack
Next.js, TypeScript, Tailwind CSS, Supabase, Jitsi, Docker, GitHub Actions
